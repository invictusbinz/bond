# Bond Design System

## Color Palette
- **Ink (dark):** #1a1714
- **Paper (cream):** #faf8f4
- **Paper warm:** #f2ede4
- **Accent (terracotta):** #c4622d
- **Accent soft:** #f0d9cc
- **Rule (border):** #e0d8cc
- **Green:** #3d6b4f
- **Green soft:** #d4e8dc

## Typography
- **Display/Headers:** Playfair Display (serif), 400 weight, elegant and minimal
- **Display italic:** Playfair Display italic for emphasis and callouts
- **Body:** DM Sans, 300-500 weight, light and readable
- **Mono/Labels:** DM Mono, monospace, 10px uppercase for eyebrows and metadata

## Components
- **Cards:** white bg, 1px #e0d8cc border, 8px radius, subtle hover state
- **Buttons (primary):** #c4622d background, white text, hover to #a0481f
- **Buttons (secondary):** transparent, border #e0d8cc, hover border + text to #c4622d
- **Labels/Eyebrows:** DM Mono, 10px, uppercase, accent color, 0.2em letter spacing
- **Spacing:** 16px-32px gaps, generous whitespace
- **Light background:** Use #faf8f4 for full-page backgrounds

## Voice
Warm, editorial, sophisticated. No tech jargon. Empathetic language that acknowledges emotional complexity.
